# markiplier-overlay-port

NeoForge 1.21.1 port of the [Markiplier overlay mod](https://modrinth.com/user/Rratt) originally created by **Rrat** for Fabric 1.20.1.

Displays a randomly-cycling Markiplier screenshot as a HUD overlay while you play. No extra dependencies - just NeoForge 1.21.1.
